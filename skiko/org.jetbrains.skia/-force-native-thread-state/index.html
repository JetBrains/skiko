ForceNativeThreadState

@Target(allowedTargets = [AnnotationTarget.FUNCTION])
expect annotation class ForceNativeThreadState

Switches the calling thread from the Runnable to the Native state around a direct call to an ExternalSymbolName function on Kotlin/Native, so the GC can proceed while the call blocks. A foreign exception that escapes the function terminates the program. Has no effect on other platforms.

Without it, a binding that blocks can deadlock the GC on Apple platforms: the native code waits for the Objective-C weak-reference lock while the thread that holds this lock waits for the GC.

Mark a binding if its native code, directly or through Skia, can:

  • call Objective-C, CoreFoundation, CoreText, CoreGraphics or Metal, including the release of their objects, such as the last unref of a typeface, font manager, GPU surface or image;

  • match fonts, create typefaces, read font names or tables, map text to glyphs, or measure, shape, lay out or draw text, because a glyph cache miss calls the platform font API;

  • create a GPU context, surface or image, wrap backend GPU objects, draw or composite into a canvas that can be GPU-backed, read or write GPU pixels, or flush or submit GPU work;

  • take a Skia lock that is held across such calls, such as the glyph cache lock or the paragraph cache lock;

  • call back into Kotlin, because the callback bridge switches the thread to the Native state when it returns;

  • wait for another thread, or block in a system call, such as reading a file;

  • run CPU work that grows with its input, such as decoding or encoding an image, path operations, or playing back a picture, because the GC waits for the call to return.

When it is unclear whether the native code can do any of the above, mark the binding.
